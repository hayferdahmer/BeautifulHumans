# Beautiful Humans — визуальный стандарт

## Направление

**Dark survival / clinical field manual.** Визуальный язык должен соединять атмосферу Project Zomboid, полевой медицинский журнал и аккуратную инженерную документацию. Это не фэнтези-стилистика RaskolClasses: переносим уровень оформления и цельность, но сохраняем самостоятельную идентичность BH.

## Типографика и композиция

- Баннер: 1200×420, крупный контрастный заголовок, короткий слоган, медицинская/анатомическая графика.
- README: короткий входной блок, бейджи, оглавление, затем тематические разделы.
- Заголовки: ясные, без чрезмерной декоративности.
- Таблицы: только для сравнений, статусов и спецификаций.
- Диаграммы: Mermaid для редактируемой логики; SVG — для брендовых иллюстраций.
- Изображения: реальные скриншоты игры должны быть помечены как реальные; концепт-арт не выдавать за интерфейс мода.

## Значение статусов

- **Foundation** — код существует и имеет автоматическую проверку.
- **Stage N** — подсистема разрабатывается в рамках текущего этапа.
- **Runtime verification** — требуется подтверждение в настоящей игре.
- **Planned** — идея или будущая задача, реализация не заявляется.
- **Verified** — есть воспроизводимый тест/лог, подтверждающий конкретное утверждение.

SVG должны быть самодостаточными, без внешних шрифтов, скриптов и сетевых зависимостей. Анимация допускается только как необязательное украшение и должна уважать `prefers-reduced-motion`.

## Правила честной визуализации

1. Не показывать придуманные показатели FPS, число пользователей, покрытие тестами или процент готовности.
2. Не считать количество модулей показателем готовности всей системы.
3. Разделять автоматические тесты и runtime-приёмку.
4. Не помечать planned-функции как работающие.
5. Не размещать скриншоты-заглушки, имитирующие реальный игровой UI.
6. Обновлять бейджи только от реально существующих workflow, релизов и метаданных GitHub.
